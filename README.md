# Sistema de Gestão de Manutenção Aeronáutica

## Descrição

Sistema web destinado ao gerenciamento de processos de manutenção
de aeronaves em uma oficina aeronáutica.

O sistema permitirá o cadastro e gerenciamento de aeronaves,
técnicos e peças, além da criação e acompanhamento de ordens
de serviço e consulta ao histórico de manutenções das aeronaves.

## Objetivo

Desenvolver um sistema para auxiliar no gerenciamento das
atividades de manutenção aeronáutica, permitindo organizar
informações sobre aeronaves, técnicos, peças e ordens de serviço.

## Funcionalidades

- Cadastro e gerenciamento de usuários;
- Autenticação de usuários;
- Cadastro e gerenciamento de aeronaves;
- Cadastro e gerenciamento de técnicos;
- Cadastro e gerenciamento de peças;
- Criação e gerenciamento de ordens de serviço;
- Atribuição de ordens de serviço a técnicos;
- Acompanhamento do status das manutenções;
- Registro das peças utilizadas;
- Consulta ao histórico de manutenção das aeronaves.
