# Requisitos do Sistema

## 6.1 Requisitos funcionais

**RF01** — O sistema deve permitir o cadastro de usuários.

**RF02** — O sistema deve permitir que usuários cadastrados realizem login.

**RF03** — O sistema deve permitir cadastrar, consultar, alterar e excluir aeronaves.

**RF04** — O sistema deve permitir cadastrar, consultar, alterar e excluir técnicos.

**RF05** — O sistema deve permitir cadastrar, consultar, alterar e excluir peças.

**RF06** — O sistema deve permitir criar uma ordem de serviço vinculada a uma aeronave, contendo a descrição do problema ou serviço, data de abertura e status da manutenção.

**RF07** — O sistema deve permitir atribuir uma ordem de serviço a um técnico.

**RF08** — O sistema deve permitir alterar e consultar o status de uma ordem de serviço.

**RF09** — O sistema deve permitir registrar as peças utilizadas em uma ordem de serviço.

**RF10** — O sistema deve permitir consultar o histórico de manutenções de uma aeronave, exibindo suas ordens de serviço anteriores, serviços realizados, técnicos responsáveis, peças utilizadas, datas e status.

**RF11** — O sistema deve permitir alterar e excluir ordens de serviço.

**RF12** — O sistema deve permitir consultar os detalhes de uma ordem de serviço, incluindo a aeronave, descrição do problema ou serviço, técnico responsável, status, datas e peças utilizadas.

**RF13** — O sistema deve restringir o acesso às funcionalidades que exigem autenticação.

**RF14** — O sistema deve permitir consultar as ordens de serviço cadastradas, exibindo informações como aeronave, técnico responsável, data de abertura e status.
